# CareHome-Leave-Management-System

## Overview

The Care Home Leave Management System is a full-stack web application designed to simplify annual leave management for care home staff.

The system enables administrators to configure annual leave entitlements at the beginning of each leave year, based on contracted working hours. Staff members can submit annual leave requests, view their allocated entitlement and remaining balance, while administrators can review, approve, or reject requests through an approval workflow.

The application provides email notifications throughout the leave approval process to keep staff and administrators informed.

This project is being developed as a volunteer initiative for a local care home and follows a structured software development lifecycle, including requirements gathering, system analysis, architecture design, implementation, testing, and deployment.

## Technology Stack

- React
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- ASP.NET Core Identity
- RESTful APIs
