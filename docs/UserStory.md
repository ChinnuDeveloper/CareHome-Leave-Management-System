# User Story For: Care Home Leave Management System

| STORY ID | TITLE | USER STORY | ACCEPTANCE CRITERIA | PRIORITY | EPIC | ACTOR | BUSINESS RULES |
|---|---|---|---|---|---|---|---|
| US-001 | Submit a Leave Request | As an employee, I want to submit a leave request by selecting the leave type, start date, end date, and providing a reason when required, so that my manager can view and process my leave request. | **AC-1:** Employee can select a leave type.<br>**AC-2:** Employee can select a leave start date.<br>**AC-3:** Employee can select a leave end date.<br>**AC-4:** Employee can enter a reason or comment.<br>**AC-5:** The system automatically calculates the total leave hours when the leave dates are selected.<br>**AC-6:** The system automatically displays the remaining leave balance after calculating the requested leave hours.<br>**AC-7:** Total Hours and Remaining Hours are displayed as read-only fields.<br>**AC-8:** Employee can submit the leave request.<br>**AC-9:** The leave request is saved with a Pending status.<br>**AC-10:** A success message is displayed after submission. | High | Leave Management | Employee | • Employee cannot submit leave requests for past dates.<br>• The end date must be on or after the start date.<br>• The total leave hours are calculated automatically by the system.<br>• Remaining leave balance is updated after submitting the leave request.<br>• If the leave balance is insufficient, the system prevents the submission and displays a validation message.<br>• The system must check department staffing rules before submission. |
| US-002 | Review Pending Leave Requests |As a manager, I want to view all pending leave requests, so that I can review them and decide whether to approve or reject each request. |	**AC-1:**	The manager can view all pending leave requests.<br> **AC-2:**	Each leave request displays the employees name.<br> **AC-3:**	Each leave request displays the employees department. <br> **AC-4 :**	 Each leave request displays the leave start date.<br>**AC-5:**	Each leave request displays the leave start date.<br>**AC-6:**	Each leave request displays its current status<br>**AC-7:**	The manager can open a leave request to review its details.<br>**AC-8:**	The manager can filter pending requests by date range.<br>**AC-9:**	The manager can refresh the list to view the latest requests.|High|	Leave Management |	Manager |	•	Manager role can review pending leave requests.<br> •	Only leave requests with Pending status appear in the pending tab.<br>•	The list is ordered by submission date. |
| US-003 | Approve Leave Requests | As a manager, I want to review and approve pending leave requests submitted by employees, so that approved leave can be recorded and employees can be informed of the decision.	| **AC-1:**	The manager can view all pending leave requests.<br> **AC-2:**	Each leave request displays the employees name.<br>**AC-3:**	Each leave request displays the employees department.<br>**AC-4:**	Each leave request displays the leave start date.<br>**AC-5:**	Each leave request displays the leave start date.<br>**AC-6:**	Each leave request displays its current status<br>**AC-7:**	The manager can open a leave request to review its details.<br>**AC-8:**	The manager can filter pending requests by date range.<br>**AC-9 :**	The manager can refresh the list to view the latest requests.|	High |	Leave Request Management |	Manager |	•	Only pending leave requests can be approved.<br> •	When approve, leave status changes from Pending -> Approved<br> •	When rejected, leave status changes from Pending -> Rejected<br>•	Approved leave cannot modified by employee.|
| US-004 | Reject Leave Request |	As a manager, I want to reject a pending leave request and provide a comment, so that employees understand why their leave request was not approved. |	**AC-1:**	When the manager clicks on Reject button, then the system shall allow the manager to reject the request.<br>**AC-2 :**	Manager provide a rejection comment and confirm rejection.<br>**AC-3 :**	When a leave request is rejected, the system shall store managers comment.<br>**AC-4:**	When a leave request is rejected, the employee shall be able to view the rejection status and manager comment.|	High | Leave Request Management	Manager	| •	Only manager shall have permission to reject leave requests<br>•	Only leave request with Pending status can be rejected.<br>•	Rejection reason must record when rejecting a leave request.|
| US-005 | Display remaining Leave Balance before request submission | As an employee, I want to see my remaining leave balance on my dashboard, so that I know how many hours I have available before I submit a leave request.	|**AC-1:**	The staff dashboard displays the “Remaining Annual Leave” balance at the top of the page, before the leave request table.<br>**AC-2:**	The balance is visible as soon as the employee logs in.<br>**AC-3:**	The balance reflects total entitlement minus taken and Approved/pending leave request.<br>**AC-4:**	The balance is shown with a clear label and unit. | High |	Leave Request Management	Employee |	•	Remaining balance=Total Entitlement-(Taken+ Pending &  Approved Requests).<br>•	Balance must recalculated immediately whenever a request status changed.<br>•	Staff cannot submit a request the brings the balance below zero.<br>•	The dashboard balance and any balance shown elsewhere must always match.|
| US-006 | Automatically update Leave balance on Request approval |	As a staff member, I want my remaining leave balance to update automatically when my leave request is approved, so that I always see an accurate balance without needing to manually recalculate or contact manager.|**AC-1 :**	When manager approves a pending leave request, the system automatically deducts the approved hours from remaining leave balance.<br>**AC-2:**	The updated balance is reflected immediately on the staff dashboard.<br>**AC-3:**	The updated balance is reflected in the manager’s Entitlements page for that employee.<br>**AC-4:**	The request moves from “Pending” tab to the “Approved” tab in the Requests page.|	High | Leave Request Management	| Manager(trigger the action), Employee(sees the result) |	•	Remaining balance=Total entitlement –( Taken +Approved+ Pending requests).<br>•	On approval, the requests hours move from “Pending” into “Approved”.|
| US-007 | Configure Annual Leave Entitlement at start of financial year | As a manager, I want to configure employees annual leave entitlement at the start of the financial year, so that staff balances are set correctly before any leave requests are made. | **AC-1:**	The manager can access an entitlements page listing all employees and their current leave entitlement values.<br>**AC-2:**	The manager can use a “Generate Entitlements” action to set entitlements at the start of a new financial year in a single action.<br>**AC-3:**	The manager can edit an individual employees entitlement manually via an “Edit” pop-up.<br>**AC-4:**	The system requires the manager to specify the financial year when generating entitlements.<br>**AC-5:**	Once entitlements are generated, the employees “Remaining Annual Leave” balance on their dashboard reflects the new entitlement immediately.<br>**AC-6:**	The system prevents accidental duplicate generation for a financial year.| High |	Leave Entitlement Management |	Manager |	•	Entitlement can only be configured by manager.<br>•	Each financial year’s entitlement values are stored separately.<br>•	Entitlement configuration must be completed before the financial year begins.|
| US-008 | Modify Employee Leave Entitlement. |	As a manager, I want to modify an employees leave entitlement during the financial year, so that I can account  for changes such as promotions, contract updates or special circumstances without waiting for the next financial year rollover.| **AC-1:**	The manager can open the Edit pop-up for any employee from the Entitlements page at any time during the financial year.<br>**AC-2:**	The manager can update the entitled hours value for that employee.<br>**AC-3:**	The updated value and balance are reflected immediately on the employees staff dashboard.<br>**AC-4:**	The system retains a record of the change for audit purposes. | Medium | Leave Entitlement Management |	Manager |	•	Only manage can modify entitlements.<br>•	Remaining balance must always recalculate as Entitles immediately after a change.<br>•	All entitled changes should be timestamped.|
| US-009 | Cancel an Approved Leave Request with Reason	| As a manager, I want to cancel an approved leave request and provide reason, so that I can handle situations like staffing shortage while keeping clear record of why the cancellation happened. | **AC-1:**	The manager can select an approved leave request from the Approved tab on the Requests page and choose a cancel action.<br>**AC-2:**	The system requires the manager to enter a reason before cancellation can be confirmed.<br>**AC-3:**	Once cancelled, the request moves from the “Approved” tab to the “Cancelled” tab.<br>**AC-4:**	The employees remaining leave balance is automatically restored once the cancellation is confirmed.<br>**AC-5:**	The cancellation reason is visible to the employees when they view that request on their dashboard.| Medium |	Leave Request Management |	Manager(performs cancellation),<br>Employee(views outcome) | •	Only manager can cancel an approved leave request<br>•	A reason is mandatory<br>•	Cancelling a request restores the balance<br>•	Cancelled requests visible in the “Cancelled” tab.|
| US-010 | Reschedule an Approved Leave Request with Reason |	As a manager, I want to reschedule an approved leave request and provide a reason for the change, so that I can adjust leave dates to meet staffing needs while keeping the employee informed of why the change was made.|**AC-1:**	The manager can select an approved leave request from the Approved tab on the Request page and choose a “Reschedule” action.<br>**AC-2 :**	The system allows the manager to enter new start and end dates for the request.<br>**AC-3:**	The system requires the manager to enter a reason before the reschedule can be confirmed.<br>**AC-4:**	Once confirmed, the request  retains its “Approved” status but reflects the new start/end dates and updated hours.<br>**AC-5:**	If the new duration differs from the original, the employees remaining leave balance is automatically recalculated.<br>**AC-6:** 	The employees dashboard reflects the updated dates and balance.| Medium	|  Leave Request Management |	Manager(perform reschedule), <br> Staff(views outcome) | •	Only manager can reschedule an approved leave request.<br>•	A reason is mandatory.<br>•	Rescheduled requests keep their “Approved” status |
| US-011 | Request Birthday Leave	| As a staff, I want to request one day of Birthday Leave on my birthday or within my birthday week, so that I can celebrate my birthday in line with the care home’s leave policy.	| **AC-1:**	Staff can select “Birthday Leave” as a leave type when submitting a request.<br>**AC-2:**	The system restricts the selectable date to the employees actual birthday or any single day within their birthday week.(within 7 days)<br>**AC-3:**	The system prevents from selecting a birthday leave date outside the permitted week window, showing a validation message if attempted.<br>**AC-4:**	The system prevents more than one Birthday Leave request being approved per employee per year.<br>**AC-5:**	Birthday Leave requests follow the same submission and approval workflow as other leave types.<br>**AC-6:**	If approved, Birthday leave is tracked separately from Annual Leave and does not deduct from the employees remaining Annual Leave balance.<br>**AC-7:**	The employee can view the status of their leave request. | Medium |	Leave Request Management | Employee(submits requests),<br> Manager(approve/rejects) |	•	Birthday Leaves is limited to one day per employee per year.<br>•	Eligible date range=employees birthday date, or any day within the defined birthday week.<br>•	Birthday leave is tracked as a distinct leave type, separate from Annual Leave entitlement and balance.<br>•	Eligibility is derived from the Date of Birth field already captured in the Employee module.<br>•	If an employee does not use their Birthday leave within the eligible window, it does not carry over or convert to Annual Leave.|
